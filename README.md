# Seleção dos Mídia

Base inicial com:
- Login
- Cadastro
- Sessão persistida no navegador
- Logout
- Redirecionamento para a tela Home
- Interface minimalista inspirada no iPhone
- Tipografia com stack nativa de iOS/SF Pro

Observação: o cadastro atual é local (localStorage), adequado para protótipo. Para produção, a autenticação deve usar um backend seguro com hash de senha e banco de dados.
